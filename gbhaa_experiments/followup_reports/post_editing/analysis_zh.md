# 四配置投影收益与梯度选词实验分析

## 结论

这轮实验已全部完成：计划 12 项、12 项通过完整重算审计、0 缺失、0 拒绝。两项修改没有改善本次 Post 的最终验证集攻击效果；组合后的 Post 优于 Pre，但劣于 Parallel。Post 四配置中最好的是同预算对照 edit_control。

## 1. 完整性和比较范围

- Citeseer，seed 15；同一结构轨迹前 60 次动作。有效结构预算为 1.6358%；来源轨迹预算 0.1 不是此次实际执行的完整预算。
- 四配置 × Post/Pre/Parallel = 12 项。每项均有 240 次实际变化的属性写入、180 次成功的逻辑生成请求；无生成、节点或分组失败。缓存命中数可以不同。
- 相同结构动作、最终结构图、干净模型预测、训练/验证划分、固定编辑代理权重与伪标签、vectorizer 和预算规则均通过匹配审计。执行时源文件指纹与当前代码一致。
- 每项实际重算了选点、访问历史、增删词计划、向量化/投影、顺序候选 NLL、所选候选、最终写入和请求缓存。三组各用其对应图求 diffusion、梯度和候选收益；这检验整套局部编辑的图状态，不仅切换 diffusion 图。
- ACC 来自 211 个验证节点；干净 ACC 为 71.0900%。只有一个种子，所以样本标准差和跨种子 95% CI 均未定义。试验完成不等于已经证明稳定性。
- edit_control 是每轮三次真实请求的新同预算对照，不能等同历史一次请求的 baseline。

## 2. 最终受害模型的验证集 ACC

单位为百分比，越低代表攻击越强。

| 配置 | Post | Pre | Parallel |
|---|---:|---:|---:|
| 同预算对照 (`edit_control`) | 66.8246 | 68.2464 | 67.2986 |
| 仅投影后收益选择 (`edit_gain`) | 68.2464 | 68.2464 | 68.2464 |
| 仅梯度选词 (`edit_words`) | 68.2464 | 70.1422 | 66.8246 |
| 两项组合 (`edit_both`) | 69.1943 | 70.1422 | 68.2464 |

## 3. 两项修改分别有没有改善

以下是相对同组 edit_control 的攻击改善量：对照 ACC − 新配置 ACC，正数代表更强攻击，单位百分点。

| 配置 | Post 改善 | Pre 改善 | Parallel 改善 |
|---|---:|---:|---:|
| 仅投影后收益选择 | -1.4218 | +0.0000 | -0.9479 |
| 仅梯度选词 | -1.4218 | -1.8957 | +0.4739 |
| 两项组合 | -2.3697 | -1.8957 | -0.9479 |

- 单独按投影后收益选候选：Post 变差 1.4218 个百分点，Pre 持平，Parallel 变差 0.9479。最终 ACC 未显示优势。
- 单独梯度选词：Post 变差 1.4218，Pre 变差 1.8957；只有 Parallel 改善 0.4739，即正确分类数量相差一个验证节点。
- 两项组合：Post 比对照变差 2.3697，且比任一单项再差 0.9479；不是本轮最优 Post。

### 2×2 主效应与交互

每个种子/组先计算：收益主效应=((c−g)+(w−b))/2，词策略主效应=((c−w)+(g−b))/2，交互=g+w−c−b。c/g/w/b 分别对应四配置 ACC。正值表示降低 ACC。

| 组 | 收益选择主效应 pp | 梯度词主效应 pp | 交互 pp |
|---|---:|---:|---:|
| endpoint_post | -1.1848 | -1.1848 | +0.4739 |
| endpoint_pre | +0.0000 | -1.8957 | +0.0000 |
| parallel | -1.1848 | +0.2370 | -0.4739 |

Post 的 +0.4739 交互并不表示组合有效：它只是两项负效应没有简单相加，组合仍比对照差 2.3697。

## 4. Post 是否优于同配置 Pre / Parallel

正值表示 Post 更强，单位百分点。

| 配置 | Pre ACC − Post ACC | Parallel ACC − Post ACC |
|---|---:|---:|
| edit_control | +1.4218 | +0.4739 |
| edit_gain | +0.0000 | +0.0000 |
| edit_words | +1.8957 | -1.4218 |
| edit_both | +0.9479 | -0.9479 |

组合 Post=69.1943%，Pre=70.1422%，Parallel=68.2464%。因此 Post 只胜 Pre 0.9479 个百分点，同时输给 Parallel 0.9479 个百分点；不能声称同时领先。差值分别相当于正确分类数量相差两个验证节点，尚无跨种子稳定性证据。
同预算对照 Post 在本次同时胜 Pre 1.4218、Parallel 0.4739；收益选择后三组 ACC 完全相同。梯度选词后的 Post 虽然胜 Pre，却输给 Parallel。
组合的 victim NLL：Post=1.297042、Pre=1.300744、Parallel=1.324466（攻击希望更高）。因此 Post 相比 Pre 的优势也仅体现在 ACC，而非两个指标同时占优。

## 5. 机制是否真的执行，以及为什么收益没有转化

### 实际候选与编辑

- 每次节点写入均有三个不同的最终投影候选（全部 12 项各 240/240 次），不是复制同一向量凑数。原始模板偶有重复，但经过不同词计划后候选仍不同。
- edit_gain / edit_both 每次均选择实际投影 NLL 最大的候选，审计未发现违反 argmax 的写入。
- 梯度 Post 的计划增词/删词全部执行（投影后的“删除”允许是幅度降低）：edit_words 5796/559 次，edit_both 8568/574 次。此处是跨轮次数，不是最终不同条目数。
- Post 各自轨迹上的累计实际属性损失增量依次为 0.063843、0.095942、1.769802、2.502508；负增益轮数依次为 10/60、8/60、0/60、0/60。这是各自轨迹的描述性局部收益，不能直接当作同一状态上的净因果效应。

### 固定攻击代理与最终受害模型之间的差距

用保存的固定代理权重做只读前向评估，统一使用最终执行后的图和各自最终特征，在同一验证集上得到：

| Post 配置 | 固定代理 ACC % | 重新训练的 victim ACC % |
|---|---:|---:|
| edit_control | 69.6682 | 66.8246 |
| edit_gain | 69.1943 | 68.2464 |
| edit_words | 62.0853 | 68.2464 |
| edit_both | 60.6635 | 69.1943 |

梯度及组合确实更能破坏固定代理的预测，但最终受害模型上的攻击表现变弱。这支持“固定代理收益没有迁移到最终评估”的判断；不能仅凭本轮确定唯一原因。固定编辑代理无 ReLU，最终默认 GCN victim 有 ReLU，且 victim 重新训练，因此这里同时存在模型形式与训练过程差异，不应把差距全部归因于重训练。额外诊断仅进行了保存权重的前向运算，未拟合模型、未生成文本、未使用测试集标签。

### 组合倾向更大扰动，而不是更好最终效果

- edit_both Post 的 240 次选择中，237 次选择计划上限 36 的第三候选（98.75%）。实际 L1 为 11754.2775，比 edit_control 的 10455.3897 高 12.42%，最终变化条目多 20.10%，但 ACC 更高、攻击更弱。
- Post 对照与组合均覆盖 205 个不同节点（240 次写入），重复比例均为 14.58%；组合的退步不能解释为本轮覆盖数减少。组合 Parallel 覆盖 223 节点，这属于观察差异，不能直接证明其胜出由覆盖造成。
- 原保留词上限、连续值阈值和 partial vocabulary 对齐仍可能导致计划外变化；组合 Post 记录 6708 次计划外条目降低。这些变化已计入真实候选损失和审计，因此不能声称所有变化都由梯度计划指定。

## 6. 本轮可支持的判断

1. 实验完整，两个机制确实被执行；没有发现本轮排名来自缺失结果或伪候选。
2. 在本次 Citeseer / seed 15 / 60 动作中，两项修改均未提高 Post 的最终 ACC 攻击效果，组合最差。
3. 组合 Post 只胜 Pre，输给 Parallel；当前证据不支持同时领先或稳定优势。
4. 当前 Post 参考配置应保留 edit_control。若继续研究，优先核查代理目标与最终 victim 的一致性；本轮不构成用组合替换主配置的依据。
